# Resultados experimentales

Esta carpeta almacena CSV y resúmenes generados durante las pruebas de profundidad y decisión.

`ejemplo_depth/` contiene dos ficheros de ejemplo:

- `cerca_depth_neck_base.csv`: serie original de profundidad y clasificación.
- `cerca_depth_neck_base_suavizado.csv`: serie obtenida tras aplicar suavizado offline.

Los resultados completos del TFG están disponibles en la carpeta externa de material
complementario enlazada desde el README principal.
